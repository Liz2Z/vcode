# VCode

专注代码阅读与 Git diff 的 macOS 原生工具。

快速找到文件，读懂类型与引用，对照每一处改动。保持轻量、清晰，让注意力留在代码上。

## 核心能力

- **浏览与查找**：树状目录浏览项目，⌘P 模糊查找文件，⌘⇧F 全文搜索，支持大小写、整词、正则和目录排除。
- **双栏 diff**：按目录查看已暂存与未暂存改动，对照完整上下文，辨认行级与字符级差异；直接暂存或取消暂存文件与目录。
- **理解 TypeScript**：语法高亮、悬停查看类型、⌘点击跳转定义；在定义处 ⌘点击查看引用。
- **连续阅读**：多标签、左右分栏、阅读位置前进／后退；重开应用恢复项目、标签与阅读位置。
- **切换工作现场**：快速切换分支、worktree 和最近项目，外部文件变化自动同步。
- **阅读 Markdown**：直接预览文档，也可切换到源码查看。

项目源码与 diff 保持只读；独立草稿可以编辑和保存。

## 开始使用

从 [Releases](https://github.com/Liz2Z/vcode/releases) 下载预览版，将 VCode 拖入 Applications 即可使用。当前提供 Apple Silicon 版本，支持 macOS 13 及以上。

打开应用后，按 **⌘O** 选择项目，也可通过 Finder 的“打开方式”打开仓库中的开发文件。TypeScript 7 原生语言服务已随应用打包，运行时不需要 Node.js 或另装 TypeScript。

应用启动后及运行期间会自动检查新预览版，有更新时可直接下载并重启安装；也可从 **VCode → Check for Updates…** 手动检查，或关闭自动检查。旧版本需先手动安装一次带自动更新能力的版本。

| 操作 | 快捷键 |
| --- | --- |
| 快速打开文件 | ⌘P |
| 项目全文搜索 | ⌘⇧F |
| 向右分栏 | ⌘\ |
| 阅读后退／前进 | ⌃− / ⌃⇧− |
| 查阅快捷键 | ⌘K，然后 ⌘S |

预览版尚未完成 Developer ID 签名与公证，首次打开可能需要在 macOS“隐私与安全性”中确认。

## 开发检查

本地与 GitHub Actions 统一执行 `bash scripts/check.sh`：准备锁定的依赖、隔离应用状态并运行完整自动化测试。日志、环境信息与退出状态保存在 `.build/check-results/`；CI 将同样的报告作为测试日志产物上传。自动化检查与实际窗口验收分别执行。

工具链基线在 `.ci/toolchain.env`：Xcode 26.2（17C52）、Swift 6.2.3、macOS SDK 26.2、arm64 Node.js 22.22.2 / npm 10.9.7。检查和构建均只在当前进程选择匹配的 Xcode，不修改系统 `xcode-select`；缺少版本时明确失败，不回退到默认版本。更新基线时同步验证本地和 CI。

GitHub 托管 runner 的 macOS 与显示缩放仍可能不同于本机；锁定编译器和 SDK 不会锁定系统 AppKit、字体或运行速度。实际系统版本会写入环境报告。
