# VCode

专注代码阅读与 Git diff 的 macOS 原生工具。

快速找到文件，读懂类型与引用，对照每一处改动。保持轻量、清晰，让注意力留在代码上。

## 核心能力

- **浏览与查找**：树状目录浏览项目，⌘P 模糊查找文件，⌘⇧F 全文搜索，支持大小写、整词、正则和目录排除。
- **双栏 diff**：按目录查看已暂存与未暂存改动，对照完整上下文，辨认行级与字符级差异。
- **理解 TypeScript**：语法高亮、悬停查看类型、⌘点击跳转定义；在定义处 ⌘点击查看引用。
- **连续阅读**：多标签、左右分栏、阅读位置前进／后退；重开应用恢复项目、标签与阅读位置。
- **切换工作现场**：快速切换分支、worktree 和最近项目，外部文件变化自动同步。
- **阅读 Markdown**：直接预览文档，也可切换到源码查看。

VCode 是只读查看器。

## 开始使用

从 [Releases](https://github.com/Liz2Z/vcode/releases) 下载预览版，将 VCode 拖入 Applications 即可使用。当前提供 Apple Silicon 版本，支持 macOS 13 及以上。

打开应用后，按 **⌘O** 选择项目，也可通过 Finder 的“打开方式”打开仓库中的开发文件。TypeScript 语言服务已随应用打包，无需另装运行时。

| 操作 | 快捷键 |
| --- | --- |
| 快速打开文件 | ⌘P |
| 项目全文搜索 | ⌘⇧F |
| 向右分栏 | ⌘\ |
| 阅读后退／前进 | ⌃− / ⌃⇧− |
| 查阅快捷键 | ⌘K，然后 ⌘S |

预览版尚未完成 Developer ID 签名与公证，首次打开可能需要在 macOS“隐私与安全性”中确认。
