# VCode 踩坑摘要

只保留实际发生、对后续排查有帮助的问题、原因和检查点。普通方案讨论、需求补充、审美取舍和逐次验收流水账不收录。同类问题合并；推测不写成定论。当前产品要求见 [UI 需求](../tests/ui/README.md)，历史执行证据见 [验证记录](verification/)。

<a id="filesystem"></a>
## 文件浏览与 Git

- **Files 不能由 Git 路径合集生成。** `git ls-files --cached` 和改动路径都包含磁盘上已删除的文件，曾导致删除项刷新后仍留在 Files。浏览清单来自磁盘，Git 只补状态；Changes 保留删除记录。暂存删除后同路径可能重新创建，不能仅凭 `D` 判断文件不存在。
- **`skipDescendants()` 只用于真实目录。** 对 `.DS_Store`、worktree 的 `.git` 普通文件调用它，已复现会跳过后一个目录的后代，使真实源码目录消失。跳过一个文件不等于跳过目录后代；符号链接也不能递归读取目标。
- **浏览范围与检索范围必须分开。** 共用一份预先过滤的清单曾把忽略文件连同浏览入口一起删除。忽略目录保留节点，展开时只读下一层；Files 匹配、Quick Open、全文搜索和最近文件候选使用独立的可检索集合。展开或阅读忽略文件不能扩大搜索范围；已跟踪例外按 Git 原生规则处理。
- **目录占位不能成为自己的子项。** 对 `src/` 扫描子项时，等于该前缀的占位路径剩余部分为空；原实现仍创建条目，产生空白行。跳过目录自身占位，保留下一层目录与文件，分别检查空目录和嵌套目录。
- **元数据过滤要覆盖所有入口。** 只在搜索中排除 `.DS_Store`，完整扫描、按需目录及 Changes 仍会显示它。共享展示规则，但保留原始 Git 状态，不把隐藏变成删除或 Git ignore。`.swp` 是编辑器交换文件，不属于 macOS 元数据。
- **显式文件列表会改变 ripgrep 的过滤行为。** 已探测到显式传入文件时，不能只依赖 `-g` 排除目录；构建候选批次时先按排除规则筛选。分批限制参数长度，流式读取结果，UTF-8 字节列转换为 UTF-16；Markdown 搜索结果定位源码，不用预览行号。
- **右键目标、选中目标和打开文档是三件事。** 定位 Files 若走普通选中回调会意外打开文件；旧菜单也可能在切项目后指向同名路径。菜单携带根目录与路径，执行时重新校验；定位时清除阻挡目标的筛选、逐层展开并抑制打开回调，保留当前阅读与另一模式的树状态。

## AppKit 布局与绘制

- **约束尺寸不等于绘制尺寸。** `NSButton.alignmentRectInsets` 曾使声明的正方形关闭按钮实际变成长方形，标题宽度断言也曾把外框内边距算成可用文字宽。核对实际 frame、alignment rect、文字固有宽和绘制区域；不要只比较约束常量。
- **图标、文字与背景需共享布局。** 自定义 cell 内缩叠加 `NSButtonCell` 的图文绘制曾导致错位。固定图标容器与图文间距，明确文字压缩策略，背景留白纳入点击区域；不要让 cell 再画第二份内容。检查长名称、窄宽度及状态切换。
- **改 bezel 后仍要检查内部居中。** `NSSearchField` 和 `NSTextField` 默认 bezel 不同；统一外形后，较高控件里的文字、图标和编辑光标仍曾偏上。搜索框按公开的 text/search/cancel bounds 协同布局，普通文本框使用 cell 的 drawing rect，依据字体度量而非固定 y 偏移。
- **固定行高不会自动居中文字。** 仅设置 20 点行高，Monaco 的 ascent/descent 留白仍不均；只平移字形又会使命中、选区和背景错位。通过 TextKit 行片段设置统一基线，行号共用该基线。不要从首字符的回退字体取整行度量，否则中文开头会改变基线。
- **不要假定 NSView 默认裁剪。** macOS 14 起 `clipsToBounds` 默认关闭；概览直接填充 `dirtyRect` 曾覆盖 Modified 正文，行号在半行滚动时侵入固定标题。显式裁剪滚动区、行号与概览，绘制时保存图形状态并裁到自身 bounds。回归检查相邻区域像素，不以控件存在或滚动值正常代替可见性。未裁剪视图的 `visibleRect` 也可能大于自身 bounds，命中需核对两者交集。
- **单栏不能只隐藏 diff 左栏并动态归零分隔宽度。** 这曾留下 NSSplitView 的旧分隔视图，在源码中央遮住字符与选区。单栏实际移除左栏，双栏重新插入，保持分隔厚度稳定并明确控制绘制。超大文本容器曾被怀疑，但未证实为该竖缝原因。
- **水平滚动起点可能合法为负。** 行号栏通过 `contentInsets.left` 预留空间；将恢复值强制 `max(0, x)` 曾把 JSON 开头移到行号栏下面。使用 `NSClipView.constrainBoundsRect`，新文件独立初始化两轴；diff 日常同步仍只同步纵向，不拿它代替文件位置初始化。
- **传统双滚动条的角落视图可能参与崩溃。** 分支切换曾在其插入和约束更新时触发 AppKit SIGTRAP；代码区局部采用 overlay 后原失败路径通过。不要再操作已移出的 diff 面板，也不要为此更改用户系统滚动条偏好。
- **图层和容器各有绘制边界。** GlassSurface 只裁内层材质曾留下外层背景突出；CALayer 保存的 CGColor 又不会自动跟随动态 NSColor。外层内容统一裁剪，按语义颜色在外观变化时重新解析背景、边框与阴影。跳转闪烁失效区域覆盖圆角留白及像素边缘，避免结束后残留细线。
- **可见间距要算到实际背景。** Recent 容器间距正确时，列表和行背景的多层内缩仍曾让左边与模块间距偏宽。比较实际绘制范围；当前项与 hover 交给同一层绘制，避免尺寸不同的两层底色叠加。
- **隐藏控件也可能留下布局槽位。** 文件夹操作按钮右侧曾保留文件状态列；移除图标也曾残留宽度。按行类型收起对应约束；复用单元格时完整重设属性与删除线，不能只设置新增状态。

<a id="interaction"></a>
## 鼠标事件、列表与浮层

- **只注册 cursor rectangles 未覆盖首次移入。** 文件树、Recent、查询框和编辑状态入口都曾出现点击后才显示手形。由容器按实际位置协调进入、移动及 cursorUpdate，覆盖整行留白；`activeAlways` 不支持 `cursorUpdate`，两类 tracking area 要分开。后台布局不抢前台指针，退出时不强制覆盖下一视图的指针。
- **指针策略不等于是否重新加载。** Recent 当前项曾因复用 `shouldSelectRow` 被排除手形。当前项可以保持导航反馈，同时点击不重开、不移动阅读位置；不能把当前状态一律当禁用项。
- **滚动能改变悬停，鼠标不必移动。** 标签只存 enter/exit 布尔值曾在滚动后留下多个旧 hover。视口或布局变化、tracking 重建后，用当前指针与可见几何重新计算；迟到事件不能复活旧状态。活动标签底色与 hover 分开处理。
- **不要依赖缓存的 clickedRow 完成文件激活。** 筛选、Changes 往返后，真实按下已到达正确行，原生跟踪循环仍曾不选择或发 action；AppKit 内部跳过的确切原因未确认。修正采用按下选中、抬起核对同一节点后激活一次，拖出取消；reload 清理旧按下状态，键盘选择保留原路径。
- **透明列表要留意浮动分组标题。** NSTableView 默认浮动 group row 曾覆盖 Recent 首行、快捷键标题越过浮层。采用普通内容标题或关闭浮动；内层滚动容器裁剪，外层保留投影。
- **浮层 action 不能只靠全局鼠标监听互斥。** 原生 action 可绕过监听，旧类型提示曾叠到新选择器。打开新浮层的 action 主动取消旧提示及迟到请求；浮层覆盖范围内的源码停止争抢 hover 和指针。
- **只读信息卡与可阅读提示不能共用关闭逻辑。** Recent 纯展示卡沿用代码提示的延时、移入保留，曾在指针离开后长期残留。Recent 行退出同步关闭并取消待显示任务；类型提示允许跨间隙移入阅读，延时关闭需带任务令牌，滚动及换文档立即失效。
- **原生弹层不一定包含在主窗口截图里。** NSPopover 可以超出主窗口；截图裁切曾被误判成界面不可用并引发不必要重构。先核对屏幕边界与实际障碍，保留已认可的原生交互。
- **菜单遍历会读到系统注入项。** 直接遍历 mainMenu 曾把系统替代命令误收入应用快捷键。由菜单构建器登记功能项，按原始对象身份筛选并弱引用，不把系统副本算作应用命令。
- **状态栏不是可靠的持续错误反馈。** 外部打开错误曾被后续刷新或同批成功项覆盖。失败要有独立可感知状态，批量有效项仍继续处理；覆盖式提示不参与阅读区占位，避免错误出现时正文下移。

<a id="editing"></a>
## 编辑、历史与异步状态

- **有 UndoManager 不等于菜单能撤销。** 文件独立 manager 有记录，但标准动作曾沿响应链落到 NSWindow 的另一份 manager。文本视图需接入 `undo:`／`redo:` 和菜单校验，测试真实菜单动作及 key equivalent；只直接调用 manager 会漏掉此故障。⌘⇧Z 还需核对字符 `Z` 与修饰键，不能仅给小写 `z` 加 shift。
- **编辑权限、文档能力和保存资格要分开。** 普通文件关闭编辑后，已有改动仍须保留并可保存；恢复暂停不能绕过全局只读。草稿与 diff 不共用普通文件权限。模式提示从当前焦点文档统一派生，不能让后台加载或光标消息覆盖入口；此前草稿切源码曾遗留 Editable 提示。
- **内容位置必须通过当前排版恢复。** Markdown 曾保存正确像素位置，却因隐藏文本容器保留有限高度而被夹回开头；单独修容器仍未解决所有往返路径。保留源内容锚点、行片段内偏移，等待解析与完整布局后映射回视口；等待期间不让临时空内容覆盖锚点。TS 同样使用 TextKit 行片段，不直接以行号乘行高。
- **Markdown 源列与 NSTextView 索引单位不同。** Foundation 解析器给出 UTF-8 字节列，编辑器使用 UTF-16；直接转换完整 MarkdownSourcePosition 曾只得到首字符范围。按源行列转换并覆盖中文、emoji、CRLF，不能只验 ASCII。
- **关闭标签、标签排列和跳转后退是不同历史。** 本项目最终采用当前编辑器组的最近激活顺序决定关闭后的标签，复用该文件视图状态；不调用导航后退。重排标签不能改变激活历史，文件、草稿和比较版本需保留独立身份。
- **同一路径也不代表同一个请求上下文。** hover、定义、引用、查询和文件读取都需按工作区、编辑器组、文档版本与请求令牌隔离；换文件、刷新及关闭要取消旧状态，不能只按路径接纳迟到结果。独立显示空结果、失败和不可读预览。
- **Recent 布局偏好不能被窗口挤压覆盖。** 区分用户选择的宽度与受最小空间约束的临时宽度，窗口恢复后再应用偏好。切换已有项目只更新元数据，不重新插到列表顶部；单独更新 lastFolder。

已知边界：Markdown 长段落曾在窄→宽→窄重排后漂移到较早段落，用户当时选择保留结果；该路径当时未修复，后续涉及重排时应先复核，不能把普通后退恢复通过当作此问题已解决。

<a id="language-service"></a>
## 语言服务与语义高亮

- **语义引用不能用同词匹配替代。** 从导入类型查询时，单靠 `isDefinition` 或 `includeDeclaration:false` 曾分别留下原声明、漏掉 import 使用。获取语义位置后，以真实 definition 位置排除目标声明，保留别名使用；同时检查遮蔽作用域。使用处跳定义、定义处查引用，避免跳回自己只闪烁一次。
- **协议内容要保留结构。** 悬停内容曾合并成固定大小的纯字符串，代码围栏原样显示、长内容截断。解析 Markdown 代码与说明，按真实字形定位成员并使用可滚动浮层；先看 LSP 实际结果再判断多级跳转缺失。
- **查询、引用和文本选区不能共用一份背景状态。** 搜索与引用曾都用 accent、概览又合并同一行集合，叠色后无法区分。独立语义色与标记列，定义绘制优先级；程序搜索选区保留复制能力，用户重新选区后恢复系统外观。diff 的占位行要通过显示行映射，不直接拿源行号画概览。
- **打包原生服务仍需运行时资源。** 去掉 Node 桥接后，原生语言服务需随包携带标准库声明与许可证，不能回退到开发机目录。比较同项目、同查询的进程树 RSS；不要把 RSS 与 memory footprint 混用，也不能未经堆分析就断言泄漏。

<a id="ci"></a>
## CI、测试与构建产物

- **相同测试名不保证环境相同。** CI 曾随 runner 默认使用另一版 Xcode，本地通过不能证明相同工具链。以 `.ci/toolchain.env`、`scripts/check.sh` 为唯一基线和完整入口；固定编译器与 SDK不代表固定了系统字体、AppKit 或执行速度。
- **布局断言必须对应产品可达尺寸。** 产品侧栏下限为 220 点，208 点独立组件压力测试曾误要求完整长标题；再比较 frame 与 intrinsic，内边距掩盖实际压缩，半点变化就触发 CI。使用实际文字布局区域，压力场景检查合理省略与不重叠，不通过放宽容差或删断言掩盖问题。此处是已核实的测试契约问题，不等于相关断言已全部改造。
- **等待事件，不用短 sleep 猜完成。** 定义探测有 90ms 防抖，旧测试等 130ms 后直接索引答案，断言失败也继续访问空数组。用 expectation 等实际回调，超时后安全退出依赖步骤；可控延迟覆盖慢返回。批量外部打开含冷工作区发现、串行读取，首轮不能套单步预算；按最终文件到达判定并输出阶段诊断，不整体放大所有超时。
- **测试窗口本身也要断言尺寸。** 设置 contentViewController 曾令窗口变成 31 点宽、0 点高，名义上的可见窗口测试并未覆盖真实排版。设置有效内容尺寸和产品最小约束，再断言视口非零。
- **共享 dist 和运行时不是冻结产物。** 并行任务曾覆盖 `dist/VCode.app` 及依赖，归档签名有效却缺少要测试的功能。从独立固定副本交付，核对实际窗口、功能、机器代码和运行时；脚本也需固定。重签会改变二进制签名数据，整个文件 SHA 不同不等于机器代码不同。
- **报告文件存在不等于包含测试。** SwiftPM 串行 XCTest 的 `--xunit-output` 曾只产生零用例的 Swift Testing XML。保留真实 XCTest 日志与退出码，不把空 XML 当完整报告，也不为报告格式改成多进程执行。
- **Actions Artifact 不等于 GitHub Release。** 构建成功并上传附件，不会自动在 Releases 出现版本。发布需独立步骤、成功依赖与相同提交的产物校验；不能在没有云端发布证据时宣称已发布。

<a id="state-and-delivery"></a>
## 持久化、密钥与交付边界

- **迁移状态要检查 AppKit 的隐式写入。** 只迁移历史仍会遗漏窗口自动保存和旧 lastFolder。XDG 四类目录按语义区分，忽略相对路径；原子写入、成功后才清理旧来源，损坏目标不能静默覆盖。测试使用隔离目录。Sparkle 内部偏好是明确例外，不扩展为其他 UserDefaults 写入。
- **提交 Secret 返回不代表页面已离开输入态。** 曾在异步提交后读取完整辅助功能树，导致私钥字段回显。提交后只读经过过滤的成功状态，敏感值不进入截图、日志、命令参数或仓库；已暴露的钥须更换并核对应用公钥与 CI 签名。不要为自定菜单预期改写 Sparkle 的原生更新会话交互。
- **禁止编辑不等于禁止提交已有修改。** `docs/PRD.md` 由用户维护；用户明确要求全部提交时，原样纳入已有内容，不格式化或回退。隔离提交范围也不等于可以擅自更换用户要求的目标分支。
- **验证动作和证据要对应。** 控件存在、AX 选中、程序化 action、实际鼠标拖动各自证明的内容不同。窗口截图不含原生弹层、Retina 坐标比例不一致或其他输入介入时，先核对环境；工具受限就停下并记录具体缺口，不能把工具异常直接归因于产品，也不反复尝试同一受限操作。
