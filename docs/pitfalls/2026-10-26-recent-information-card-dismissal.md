# Recent 信息卡片移出立即隐藏

## 问题与纠正后的预期

用户指出 Recent 项目信息卡片停留过久，并明确要求鼠标移走就隐藏，因为卡片不需要操作。该规则只用于 Recent 信息展示，不能照搬需要移入继续操作的代码类型提示规则。

## 原因

已核实 RecentWorkspaceHover.leave 使用两秒延迟关闭，卡片本身还注册鼠标移入事件来取消关闭。此前沿用了代码提示可操作卡片的交互，导致纯展示信息残留。

## 修正措施

项目行退出时同步 dismiss，同时取消待显示任务、移除卡片和事件监听；删除两秒关闭计时器与卡片自身保持显示的 tracking。保留原有显示等待，不修改代码类型提示。修订 Recent UI 预期，并在现有卡片回归中检查立即隐藏、窗口移除和显示前退出不再迟到弹出。

## 检查点与验证边界

- 先区分纯展示提示和需要操作的弹层，不让两者共用关闭时序。
- 同时覆盖卡片已显示和仍在等待显示两种退出状态。
- 不因移入已离开项目行的卡片继续保留旧信息。
- 真实鼠标悬停此前属于工具受限项；不重复尝试受限动作，不用直接调用 leave 冒充物理移出验证。本记录写入时最终验证尚未完成。
