# 用户维护文档的提交范围

## 问题与纠正后的预期

用户要求推送时，代理将“docs/PRD.md 由用户维护，禁止代理修改”扩大解释成不纳入提交。用户明确纠正“都提交了”，本次应连同该文档已有改动一起提交、推送，保留内容原样。

## 原因

混淆了编辑权限与版本提交范围。禁止代理编辑用户维护文档，不等于禁止按用户明确指示提交其已有修改。

## 修正措施

本次将用户现有 PRD 改动纳入提交；只检查 diff 和提交范围，不编辑、不格式化、不回退文档。产品与测试验证仍遵循现有推送要求，不能从“全部提交”推定免测。

## 检查点

- 分别判断是否允许编辑、是否应提交已有内容，不自行将两者绑定。
- 用户明确选择全部提交后，核对暂存区包含用户文档，提交前后内容哈希一致。
- 保留用户原有排版和空白，不以清理格式为由改动 PRD。
