# 目标闪烁要清除完整绘制范围

## 需求与预期

跳转到定义后，目标标识符闪烁高亮 2 秒，再完全消失；连续跳转重新计时，切换文件清除旧提示。高亮不修改源码、语法属性或光标位置。

## 已核实的问题与修正

原生布局管理器中的圆角背景比字形范围多出留白。实际截图发现，仅调用按字符范围的显示失效方法，会在动画结束后残留一条细边。重绘范围必须覆盖含留白的完整矩形，并对像素边界取整，而不是只重绘字形内部。

闪烁使用独立的渲染状态和可取消计时器，不覆盖 hover 使用的临时背景属性；计时器同时校验实例身份，避免旧任务影响新目标。

## 检查点

- 验证实际 ⌘点击跨文件和同文件跳转，既要看见明暗变化，也要检查结束后四边没有残留。
- 覆盖 Unicode、diff 占位行、已打开文件和连续跳转的行列位置。
- 文件替换、关闭标签和工作区切换必须清理状态及计时器。
- 系统减少动态效果时保持静态提示，持续时间仍为 2 秒。
