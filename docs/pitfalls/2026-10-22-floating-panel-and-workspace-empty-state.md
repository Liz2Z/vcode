# 浮层要有层级，空状态要区分工作区是否已打开

## 问题与用户纠正后的预期

用户截图指出 Recent 浮层与主内容背景无法区分；项目已打开时，中间仍展示 Open Folder，状态含义错误。

预期：浮层以同一灰度体系中的亮度差、圆角和外投影体现层级，保持分隔线克制；项目打开且无文件标签时提示从左侧选择文件，只有未打开项目时展示中间的打开目录按钮。

## 已核实原因与修正

Recent 列表与主内容区都使用 Theme.background，原有投影未形成足够可见的区别。改用独立的浮层底色与明确的 CALayer 投影路径，列表使用同一底色，按内容数量收紧浮层高度。

旧 WelcomeView 只根据是否有文件标签显示欢迎内容，没有区分已有工作区的情况。工作区成功打开后更新空状态语义，关闭最后一个文件不清除工作区状态；中间的打开按钮与快捷键提示一起隐藏，并收回其布局留白。

## 防止再犯

- 分别在空状态、源码和宽窄窗口中实际检查浮层，不只确认控件存在或阴影属性已设置。
- 明确区分没有项目、已有项目但没有文件、文件加载中及读取失败，不复用不符合当前状态的引导。
- 检查首次打开项目、关闭最后标签、工作区切换，顶部打开目录操作仍可使用。
- 保持筛选、整行点击、键盘打开、Escape 和点击外部关闭的原有交互。
