# 侧栏圆角、状态色与提醒点需按可见内容检查

## 问题与纠正后的预期

用户指出浅色侧栏右上角背景突出，要求修复；明确的问题报告不应再重复询问是否需要修复。用户另要求 Git 状态色更鲜明，Changes 提醒点应紧贴标题文字的右上角。

## 原因

代码确认 GlassSurface 只给内层原生材质设置圆角，外层没有统一裁切；这可能让材质绘制或内容在圆角外露出，截图对应的具体绘制层尚未通过实窗逐层确认。文件状态此前复用界面强调色及柔和红绿色，没有独立的状态调色板。提醒点约束在整个按钮右上角，按钮变宽时会离开居中的标题。

## 修正措施

GlassSurface 外层按相同半径裁切材质和内容；文件状态单独使用饱和度更高的橙、绿、红动态颜色，分类计数及通用强调色保持原值。提醒点改为相对按钮实际标题视图定位，保留原有大小、光晕、显隐和点击行为。同步补充 UI 需求与预期，不修改用户维护的 PRD。

## 防止再犯

- 圆角要检查整个容器及其子层的裁切，不能只看原生材质的 cornerRadius。
- 状态色与全局强调色分别定义，同时检查普通、hover、选中背景的清晰度。
- 标题附属标记锚定文字，不能用等宽按钮边缘代替文字边缘。
- 明确的缺陷反馈按修复请求推进，不重复询问是否修复。
