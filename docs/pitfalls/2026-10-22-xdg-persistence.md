# 持久化统一使用 XDG 目录

## 问题与预期

历史记录最初沿用原有 UserDefaults，用户新增要求所有持久化数据遵循 XDG。最近访问记录、上次工作区和窗口布局属于状态，应存放到 XDG_STATE_HOME，而不是用户数据目录或 macOS 偏好文件。

## 原因与修正

原应用同时使用 lastFolder 偏好和 AppKit 窗口自动保存；只迁移新历史记录会遗漏既有状态。共享目录解析处理四类 XDG 路径，忽略相对值并使用规范默认值；工作区 JSON 统一保存历史、上次目录和窗口布局，采用原子写入。移除窗口自动偏好写入，成功迁移后才清理旧键，已有 XDG 状态优先。

## 防止再犯

- 按状态、配置、数据、缓存的语义选择目录，不把所有内容塞进 DATA_HOME。
- 覆盖环境变量未设置、空值、绝对值和相对值；测试注入独立目录，不能写入用户真实历史。
- 迁移失败要保留来源，损坏的目标不能静默覆盖；检查实际磁盘文件和重启恢复。
- 已有目录不改权限，新建目录使用 0700；目录只在需要写入时创建。
- 原生列表必须验证完整行可点和键盘选择，不能只验证内部查询或回调。
