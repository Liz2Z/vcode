# CI 打包不属于 UI 测试

## 问题与用户纠正

配置 GitHub Actions 自动打包时，将推送触发、产物格式、架构和打包失败行为写进了 `tests/ui/README.md`。用户明确指出这些不属于 UI 测试，要求移除。

## 原因与正确预期

机械套用“新增功能补充 UI 用例”的约定，没有先判断变更是否涉及界面行为。该约定不能把构建、发布和产物校验变成 UI 测试。UI 文档只记录真实界面交互与可见结果；本次 CI 配置没有新增界面行为。

## 修正与检查点

- 删除本次增加的安装包章节，恢复原有 UI 需求文档。
- CI 的触发方式、构建产物、下载位置和签名状态放在项目 README；工作流及打包脚本承担对应的自动验证。
- 后续先判断变更是否影响 UI，再决定是否修订 UI 用例；不得为满足形式要求添加无关条目。
