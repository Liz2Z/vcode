# Diff 概览条不能覆盖右栏正文

## 问题与纠正后的预期

新增概览条后，代理实窗截图显示右栏正文及 Modified 标题空白，但辅助功能树仍有内容、控件与同步滚动值。用户随后明确反馈“右侧栏空白”，此项记录为用户验证失败，不能继续归为截图限制或以自动化通过替代。

预期：概览条只能在右边缘自身的窄区域内绘制，双栏标题和正文正常显示；首次打开、点击／拖动概览、滚动、刷新和窗口缩放后均不被覆盖。

## 原因核查

静态检查发现 DiffOverview.draw 直接填充 dirtyRect，且没有显式启用 clipsToBounds 或将绘制区域裁剪到自身 bounds。本机 AppKit SDK 的 NSView.h 明确说明 clipsToBounds 在 macOS 14 起默认 NO。绘制越界覆盖相邻内容是当前排查方向；尚未通过修正前后对照确认根因，不提前写成已证实。

## 修正措施与验证状态

已保存失败截图及用户确认到验证记录。按 AGENTS.md，本轮仅记录和只读核查，产品与测试尚未修改；已请求用户明确授权修复，再补边界回归并重新进行固定构建实窗验证。

## 防止再犯的检查点

- 自定义窄条视图必须显式约束背景和标记的绘制边界，不假设 dirtyRect 总在 bounds 内或系统默认裁剪。
- 回归需检查正文和相邻标题确实可见，不能仅断言概览几何、控件存在和滚动数值。
- 自动化、代理实窗和用户验证分别记录；用户确认的可见错误直接记为失败。
- UI 阶段发现问题先记录，得到明确修复指令后才修改产品或测试。

## 用户授权修复

用户明确回复“修复并重新验证”后，新增像素回归在原实现中复现越界填色；随后为概览显式启用 clipsToBounds，并在 draw 内保存绘图状态、裁剪至自身 bounds，仅填充 bounds 与 dirtyRect 的交集。像素回归同时检查旁边正文区域和上方标题区域仍保留原颜色，概览内部继续正常绘制。17 项概览、视口和阅读展示回归通过；修复后实窗结果待补录，不能提前视为通过。

## 后续交互补充

修复后用户截图已显示左右正文，随后要求隐藏左栏中间的原生纵向滚动条。此反馈作为明确的新修改指令：双栏仅保留右侧概览，任一栏滚轮／触控板仍同步纵向浏览，横向滚动不变，源码模式仍使用原生纵向滚动条。原方案沿用了左栏默认滚动条，未收敛重复的纵向导航入口；检查时应同时观察中间边缘和右边缘，不能只看新增概览本身。后续验证按这次更新后的构建重新固定版本，不将修改前截图算为最终版本通过。

## 最终构建复验

17 项相关回归与发布构建通过。固定最终版本实窗确认右栏正文与标题恢复，双栏原生纵向滚动条隐藏，左右正文滚轮仍联动概览；窗口缩放后未再出现覆盖。像素回归与修复前后实窗对照支持越界背景绘制为本次覆盖原因。概览首尾连续拖动因工具命中限制标为需要用户验证，已询问，不重复尝试。其余尚未完成的实窗操作保留在 docs/verification/2026-10-26-diff-overview.md，不能把本次局部复验写成全量 UI 通过。

## 顶部标题与正文／行号交界处

用户随后截图指出 Original / Modified 标题下沿渲染异常：可见行号与正文在顶部的截断观感不一致。预期固定标题区域保持干净，滚到半行时，行号与对应正文以同一视口边界裁剪，不出现行号侵入标题、残留文字或上下错位。

静态检查发现 CodeGutter 会主动绘制视口前后额外行，其 drawHashMarksAndLabels 没有显式设置裁剪，类本身也未开启 clipsToBounds；在现代 AppKit 默认不裁剪的条件下，负 y 行号可能画到视口外。该项目前是核查方向，尚未通过回归及修复前后实窗对照确认，不把正常半行滚动直接认定为排版 bug，也不提前确认根因。

本轮先记录用户提供的可见失败，未修改产品或测试，已按 UI 约定请求明确修复并重新验证。后续回归应覆盖非整行偏移、左右同步、上下边界、行号与正文一致裁剪以及固定标题区不受影响；不能只补概览自身裁剪就推定所有原生子视图边界正确。

## 顶部裁剪修复实现

用户明确授权修复并重新验证后，新增双栏像素回归，在多个非整行滚动位置比较固定标题底部像素。确认使用相同最终测试时，旧裁剪实现有 8 项边界断言失败；启用滚动区域和行号栏的 clipsToBounds，并在行号绘制内保存／恢复图形状态、裁剪到自身 bounds 后通过。保留自然半行滚动及原始行高，不把阅读位置吸附到整行。18 项概览、视口与阅读展示相关回归、发布构建通过，后续固定版本实窗结果另记。

## 顶部裁剪修复实窗结果

固定构建中，在同一文件和 0.3333 概览位置进行修复前后对照：旧版行号侵入 Modified 标题，修复后消失，行号与正文沿同一边界裁剪。左右滚轮和另一个 0.3339 位置复验正常。结合相同回归在旧实现中 8 项标题像素断言失败、修复后通过，确认本次异常是行号越界绘制。18 项相关测试与发布构建通过；151 个源码和测试等冻结文件指纹未变。保留自然半行滚动，不能把“全部行都显示完整”当作本次预期。证据和未完成的其他项目见 docs/verification/2026-10-26-diff-overview.md。
