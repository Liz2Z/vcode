# Diff 概览滑块需要足够宽度和对比

## 问题与纠正后的预期

用户截图指出 diff 右边缘滚动条太窄、不明显。该区域是概览及可视范围滑块，预期无需悬停也能识别并容易命中拖动，悬停和拖动有更强反馈；不扩大普通源码、文件树或标签栏滚动条。

## 已核实原因

概览固定宽度为 14 点，扣除两侧留白后滑块只有 12 点。静止时使用 muted 色的 0.13 透明度，浅色背景下混合后的灰色较淡。此前统一收细滚动条的偏好不能替代本次概览的具体可操作性要求。

## 修正措施

先调整为 20 点；用户进一步明确 20 点仍窄，改为 30 点，可视范围滑块使用正文灰度色的 0.32 透明度，悬停 0.42，拖动 0.52。保留红绿改动标记、裁剪边界、双栏同步和源码模式收回占位的行为。更新现有几何／裁剪回归与 UI 预期。
