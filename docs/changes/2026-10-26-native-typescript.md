# TypeScript 原生语言服务

TypeScript 后端从 Node + typescript-language-server + JavaScript tsserver 替换为微软 TypeScript 7.0.2 的 macOS 原生程序，Swift 直接通过 stdio LSP 连接。应用包包含原生二进制、标准库声明与许可证，不再包含 Node 和旧语言服务脚本；npm 仅在构建阶段下载锁定版本。

保留现有类型悬停、多层定义跳转、定义处引用列表、文件内语义高亮、文档更新及故障恢复交互。原生服务把 import 别名也视为声明，因此查询引用时先取含声明的语义结果，再移除真正的定义位置，保持 import 仍计入使用列表，不降低旧回归的数量断言。

35 项相关自动化测试、独立 release 构建及 ZIP / DMG 打包检查通过。实窗已确认 TypeScript Ready，实际应用子进程为原生 tsc；悬停、使用处 ⌘点击、定义处 ⌘点击的实窗操作受到其他窗口操作干扰，标记为需要用户验证，尚未算通过。本次未执行全量 UI 验收，未提交或推送。

同一真实项目、同一文件与语言查询序列的独立进程对照中，服务进程树 RSS 约从 909 MB 降为 416 MB，下降约 54%。这是单次采样，非泄漏诊断或所有项目的保证；不是资源窗口 memory footprint 的同口径数字。详细记录见 docs/verification/2026-10-26-native-typescript.md。


用户已在“Go 原生服务测试”窗口确认悬停、跳转与引用列表正常，记录为用户实测通过。后续新增的测试版辨认需求采用已有红蓝光剑写实 v2 图标：本地默认构建与 GitHub 预览发行使用 preview，显式 release 构建使用灰白折纸图标；不再依赖菜单名区分版本。图标资源替换与两种构建选项的素材一致性检查通过，重开后的 Dock / 应用切换器显示因锁屏尚待确认。
