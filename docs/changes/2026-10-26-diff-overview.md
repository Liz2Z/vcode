# Git diff 改动概览

双栏 diff 右边缘增加 14 点宽的概览条：删除在红色左列，新增在绿色右列，替换行同时标记。位置使用现有 diff 对齐行（包含占位行），沿用当前文字行高与文档尺寸；不重新读取 Git 或绘制缩小代码。

当前可视范围用中性透明滑块表示，悬停和拖动加深反馈。点击轨道定位，拖动滑块连续浏览到首尾，左右正文同步，保留各栏水平位置；滚轮、原生滚动、阅读位置恢复和尺寸变化同步更新概览。双栏均隐藏原生纵向滚动条，统一使用右侧概览；任一栏正文仍支持滚轮与触控板纵向同步浏览，两栏横向滚动不变。普通源码保留原生纵向滚动条。

各编辑器独立显示当前比较版本；切回源码时隐藏并收回占位。标记沿用主题中的增删颜色。新增回归覆盖对齐占位、增删分列、长短和空文件、拖动、首尾边界、横向位置、双栏同步、主题渲染、刷新及源码切换；UI 需求与预期同步补充在 tests/ui/README.md。

验证结果见 docs/verification/2026-10-26-diff-overview.md。

修复自定义概览背景和行号越界绘制：为概览、滚动容器和行号栏明确限制绘制边界，避免正文被概览背景覆盖、行号侵入固定标题。非整行滚动时正文和行号一致裁剪，保留原行高与阅读位置；新增相邻区域及固定标题的像素回归。
