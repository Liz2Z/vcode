# 普通文件编辑验证

## 范围与实现

用户要求普通文件支持编辑。复用现有 NSTextView 草稿编辑能力，项目／worktree 内每个路径使用同一个 SourceEditStore 工作副本，双编辑器组同步文本与未保存标记。各文件独立撤销记录；其他组或外部修改内容时清除过期撤销。diff 保持只读，Markdown Source 可编辑，Preview 使用当前工作副本。

⌘S 先比较实际磁盘字节，再经 NSFileCoordinator 协调与原子写入；保留 UTF-8 BOM、换行与权限。外部修改／删除／符号链接替换拒绝覆盖并保留编辑内容。Save Copy As 导出副本，原标签身份和未保存状态保留。保存后刷新工作区、Git 和项目搜索。

文件关闭、批量关闭、关闭分栏、项目／分支／worktree 切换、关闭窗口和应用退出使用保存／放弃／取消决策。多文件操作在全部确认后再应用放弃；取消和保存失败终止后续操作。普通文件恢复内容与磁盘基线在 XDG DATA_HOME/source-edits，读取布局仅保留路径及阅读位置；启动恢复时载入非活动标签，原文件已删除时仍能保留本地内容。草稿继续使用原有持久化及退出恢复规则。
