# 可编辑文本标签验证（2026-10-26）

## 实现范围与自动化

在项目标签栏留白双击或通过 ⌘N 新建独立文本草稿。使用 AppKit NSTextView 的编辑、撤销与剪贴板能力；项目源码和 Git diff 保持只读。⌘S 保存、⌘⇧S 另存，未保存文本关闭前提供保存／放弃／取消。草稿内容保存在 XDG DATA_HOME，文档 UUID、标签顺序及阅读锚点随 worktree 阅读会话保存在 STATE_HOME。

新增 8 项测试覆盖草稿与真实文件的身份隔离、旧版会话解码、精确 Unicode／换行持久化、损坏数据保护、外部变更防覆盖、编辑与源码往返、会话／光标恢复、原生撤销重做、行号映射、空白双击命中，以及控制器和分栏切换的模式提示。最终 8 项新增测试与 8 项既有标签测试共 16 项通过；此前另执行阅读会话恢复、分栏、阅读历史与快捷键等相关回归，发现的批量关闭重复选中文件问题已修正，相关标签回归重新通过。不把此前结果表述为最终版本全量测试。

最终发布构建通过。日志与固定构建保存在本地 `.build/diagnostics/editable-tabs-20261026/` 的 `final-tests.log`、`final-release.log` 和 `VCode Editor Preview.app`。预览使用独立应用身份、临时 Git 项目及隔离的四类 XDG 目录。

## 实际窗口验证

首轮固定预览实际完成：

- 标签栏留白单击不新建，双击只新建一个 Untitled 标签并自动聚焦；双击已有标签只选择该标签，没有新建。
- 多行英文、中文与 emoji 输入成功，行号更新；⌘Z 清空该次插入、⌘⇧Z 恢复同一内容。
- ⌘W 关闭非空草稿出现应用样式的 Save／Don’t Save／Cancel 提示，Cancel 后标签和内容保留。
- ⌘S 打开保存面板，选择隔离测试目录后保存成功，标签名更新为 draft-note.txt，编辑标记消失。磁盘文本与输入逐字相同，最后一行没有被自动追加换行。
- 项目源码正文不提供可编辑属性，实际在正文按键未改动源码；草稿则具有可编辑属性。

首轮发现：切回源码后状态栏残留 Editable。按 AGENTS.md 暂停修改并报告；收到用户明确“修复并重新验证”后修改状态更新入口、补回归测试、重新构建。没有把 UI 阶段发现问题自行当作修复授权。

修复后的最终固定预览实际完成：

- 从草稿直接点击源码标签后，尚未点击正文，底部已显示 Read Only。
- 左栏草稿、右栏源码分别聚焦，状态文字和语言区域均跟随当前组；右栏打开源码不改变左栏草稿内容。
- 右侧空编辑器标签栏双击可独立新建草稿并输入；右组阅读历史后退返回该草稿的内容，左组保留原内容。
- ⌘N 新建空草稿，⌘W 直接关闭空标签，没有不必要的保存提示。
- 正常退出并重新启动，恢复两栏、各自的标签顺序及当前标签；左侧未保存的多行中文草稿仍可编辑，右侧源码与未激活草稿的标签引用保留。
