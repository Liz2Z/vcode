## 实际窗口

使用固定发布构建的独立预览应用与临时 Git 项目，四类 XDG 目录隔离；没有操作用户原应用的阅读会话。

- 依次打开 A、B、C，再访问 A、B；标签排列仍为 A、B、C。⌘W 关闭 B 后激活 A，没有按右侧相邻选择 C。
- A 关闭前的可见顶行约为第 69 行，光标点击后状态为第 77 行第 67 列。关闭 B 返回 A 后，横向滚动值保持 0.2682526661197703，纵向值由 0.38 恢复为 0.3800992282249173，属于内容锚点按实际排版定位后的微小差异。精确选区／光标偏移由控制器集成测试对照；实窗不将滚动值相近单独当作光标验证。
- 点击 A 标签的关闭按钮后，剩余的 C 正常激活；没有重新打开已关闭的 B。
- 创建右组，在右组分别访问 A、B、C、A、B。⌘W 关闭右组 B 后回到右组 A；左组 A 及其位置保持。关闭右组非当前 C 时当前 A 不变。
- 在右组新建并输入未保存草稿，⌘W 出现保存提示；Cancel 后草稿及文本保留，再次关闭并选择 Don’t Save 后返回右组 A。
- 关闭右组最后一个标签后回到左组，左组 A 的横纵位置与分栏前对应。对非当前 C 右键选择 Close Others 后仅保留 C，关闭 C 后显示项目空状态，没有残留正文或标签。

一次滚动操作报告窗口不可用，之后窗口状态与截图正常；改用原生滚动条值完成视口设置。全文文本元素中心落在屏幕外，未将工具无法点击该中心认定为应用故障，依据截图点击可见代码，状态栏确认光标位置。一处分栏动作后读取辅助功能状态失败，重新观察确认分栏已成功创建，没有重复执行分栏。
