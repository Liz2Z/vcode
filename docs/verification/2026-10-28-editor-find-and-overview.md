# 编辑器查询与概览最终调整

## 本轮范围

⌘F 当前编辑器查询；右上角原生玻璃悬浮框，不改变正文布局，避开 minimap 和 diff 固定标题。支持字面量、大小写、整词、命中数量、前后定位、首尾循环、关闭和正文／概览同步高亮。概览宽 60 点，彩色标记固定 4 点，右侧 Git 红绿紧挨着，黄色引用／查询独立在中央；灰色滑块最小高 80 点。

查询覆盖源码、Markdown Source、草稿和 diff 当前聚焦版本，按编辑器组隔离，异步结果取消与版本校验；草稿编辑更新结果但不主动改选区。菜单及快捷键目录同步提供 ⌘F、⌘G、⌘⇧G，项目查询 ⌘⇧F 保留。
